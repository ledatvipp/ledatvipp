# Le Dat VIPP Portfolio

Portfolio static theo phong cách executive / premium, tập trung làm nổi bật sự uy tín, đẳng cấp cá nhân và cảm giác chuyên nghiệp khi người khác nhìn vào.

## Thành phần chính

- `index.html`: bố cục portfolio với các section hero, trust signals, core expertise, process, case studies và contact.
- `styles.css`: hệ thống giao diện premium với nền tối, glassmorphism, typography mạnh và responsive layout.
- `script.js`: dữ liệu mẫu để cập nhật nhanh các chỉ số, vai trò, trust signals, timeline, project và contact.

## Chạy local

```bash
python3 -m http.server 8000
```

Mở `http://localhost:8000` trong trình duyệt.

## Nên chỉnh trước khi dùng thật

- Tên, nghề nghiệp, số năm kinh nghiệm và các chỉ số thành tích trong `script.js`.
- Mô tả cá nhân, định vị bản thân, case study thật và lời chứng thực thực tế trong `index.html` + `script.js`.
- Ảnh đại diện hoặc ảnh chân dung để tăng nhận diện cá nhân.
